# DataViz Dashboard

DataViz Dashboard is an interactive analytics dashboard built using React and modern frontend technologies.  
The application is designed to visualize structured data through charts, metrics, and dashboards in a clean and responsive interface.

The project demonstrates building scalable dashboard interfaces using reusable React components and modern UI practices.
